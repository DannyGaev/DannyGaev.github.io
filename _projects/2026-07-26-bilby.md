bibly exploits the usual necessity for DNS abused by DNS tunneling, but encodes data into the IP addresses themselves. There are currently two modes:

<ul>
    <li> Single-byte exfiltration </li>
    <li> Triple-byte exfiltration </li>
</ul>

Single-byte mode offers the lower-throughput data exfiltration and requires far more time than triple-byte mode, though as a result decreases the probability of identification. This project will be updated with octet-byte exfiltration via IPv6.
